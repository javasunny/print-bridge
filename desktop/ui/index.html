连接你的打印机

每台打印机拥有独立地址，任务始终交给绑定的 Windows 队列。

纸张固定为 A4。修改现有打印机请先点击下方“编辑”。
如何在 macOS 添加打印机？
  1. 启动服务，放行 Windows 防火墙的对应端口，仅限可信私有网络。
  2. 在“系统设置 → 打印机与扫描仪”中添加 IP 打印机，使用 IPP 协议。
  3. 地址填写 Windows IP 和端口，队列填写 ipp/printers/桥接ID；或使用下方复制的完整 IPP 地址。
  4. 若开启设备认证，用户名填写设备 ID，密码填写创建时显示的令牌；关闭认证时无需填写。

PDF、驱动选择和认证方式须在目标 macOS 上验证。此版本不宣称支持 AirPrint；若系统要求其他文档格式，请停止并记录兼容性问题。
