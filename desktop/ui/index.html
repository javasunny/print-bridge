macOS 添加步骤
  1. 启动服务，Windows 防火墙放行对应端口，仅限可信私有网络。
  2. 打开“系统设置 → 打印机与扫描仪 → 添加 → IP”。将每台打印机的 Address、Protocol、Queue 分别填入对应位置。
  3. Name 可填写共享打印机的显示名称。在 Mac 浏览器打开该队列的 PPD 下载地址并保存文件。Use 选择 Other，再选择下载的 Print Bridge PDF PPD。
  4. 开启认证时，用户名填设备 ID，密码填令牌；关闭认证时无需填写。

纸张和双面选项以每台打印机的已验证配置为准；修改能力后需下载新 PPD 并更新 Mac 队列。已提交表示交给 Windows，不代表已经出纸。
