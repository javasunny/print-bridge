打印机配置

已验证支持的纸张
Mac / iPhone / iPad 添加步骤
  1. 启动服务，Windows 防火墙在私有网络放行服务 TCP 端口和 Bonjour UDP 5353。
  2. Mac 打开“系统设置 → 打印机与扫描仪 → 添加”，在默认列表选择共享打印机，Use 选择 AirPrint，无需下载 PPD。
  3. iPhone / iPad 与 Windows 处于同一局域网，在应用的“打印 → 选择打印机”中选择共享名称。
  4. 开启认证时，用户名填设备 ID，密码填令牌；关闭认证时无需填写。自动发现失败时，Mac 可手动填写 Address、Protocol、Queue；旧 PPD 仍可作为备用。

纸张和双面选项以每台打印机的已验证配置为准；修改能力后，Mac 可能需要重新添加队列。已提交表示交给 Windows，不代表已经出纸。iPhone/iPad 实际打印仍需联机验收。
